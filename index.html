發現費率不對嗎？

各縣市的計程車費率隨時可能調整，我們不一定第一時間發現。如果你搭車時發現這裡算出來的跟車上的表差很多，或是你的縣市還沒被收錄，到這裡留言告訴我們就可以，寫一句話也沒關係。

如果你會寫程式，也非常歡迎直接發 Pull Request，改一行費率數字就是很棒的貢獻。

覺得好用的話，順手到 GitHub 幫我們按顆星星 ⭐ —— 這是我們繼續維護費率的動力。

這是好玩用的仿真跳表，依各縣市公告費率估算。手機 GPS 量到的距離和車上計程表本來就會有落差，過隧道、走地下道、在高樓之間穿梭時落差會更明顯。實際要付多少，一律以車上的計程表為準，這裡的數字和乘車證明不能拿來當作交易、報帳或申訴的依據。真的有爭議，記下車牌和時間，打 1999 或各縣市交通局的申訴專線。

設定

費率

春節期間各縣市約加收 30–50 元；台南、高雄、屏東在颱風假時另加 50 元。實際金額看當年公告。

聲音

聽不到的話：確認手機音量；iPhone 若是 iOS 16 或更舊，請把側邊的靜音開關關掉。

其他

iPhone 要全螢幕：在 Safari 按「分享」→「加入主畫面」，之後從主畫面的「跳表」圖示打開，就沒有網址列了。手機橫放就是整台表。
