這個網站不會知道你去了哪裡

  • 車資是在你自己的手機裡算出來的，沒有送到任何地方去。
  • 你的位置只用來量這一趟走了多遠，量完就丟掉。關掉這個頁面，什麼都不會留下。
  • 不用註冊、沒有帳號、沒有廣告、不追蹤你。
  • 不放心的話可以自己試：把網頁打開之後轉成飛航模式，跳表照樣會走 —— 因為它本來就不需要網路。
  • 不想再讓它讀位置，隨時可以在手機的瀏覽器設定裡收回權限，這個網頁不會有任何意見。

同場加映

  • 密碼外洩查詢與強度檢測 看看你的密碼有沒有被外洩過、多久會被破解。跟這個跳表一樣，密碼不會離開你的瀏覽器。
  • 新北垃圾車倒數 選你家附近的清運點，看垃圾車還有幾分鐘到，可以加進手機日曆。台北也有一個。
  • 颱風假機率計算器 用停班停課的法規門檻加上近十年紀錄，估算明天到底放不放。

發現費率不對嗎？

各縣市的計程車費率隨時可能調整，我們不一定第一時間發現。如果你搭車時發現這裡算出來的跟車上的表差很多，或是你的縣市還沒被收錄，到這裡留言告訴我們就可以，寫一句話也沒關係。

如果你會寫程式，也非常歡迎直接發 Pull Request，改一行費率數字就是很棒的貢獻。

覺得好用的話，順手到 GitHub 幫我們按顆星星 ⭐ —— 這是我們繼續維護費率的動力。

這是好玩用的仿真跳表，依各縣市公告費率估算。手機 GPS 量到的距離和車上計程表本來就會有落差，過隧道、走地下道、在高樓之間穿梭時落差會更明顯。實際要付多少，一律以車上的計程表為準，這裡的數字和收據不能拿來當作交易、報帳或申訴的依據。真的有爭議，記下車牌和時間，打 1999 或各縣市交通局的申訴專線。
